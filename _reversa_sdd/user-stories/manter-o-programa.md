# User stories — Manter o programa

- **US-09** Como operador, quero que o catálogo e as frequências se atualizem sozinhos sem abusar dos servidores. 🟢 (`catalogo-e-tle`)
- **US-10** Como operador, quero receber versões novas automaticamente e com segurança, só do site oficial. 🟢 (`atualizacao-ota`)
- **US-11** Como operador, quero usar o programa no meu idioma e com tema legível à noite. 🟢 (`interface-e-idiomas`)
- **US-12** Como operador, quero exportar um log sem dados pessoais para pedir suporte. 🟢 (`diagnostico`)
- **US-13** Como mantenedor, quero publicar uma versão com um merge e ter os clientes avisados pelo OTA. 🟢 (`build-e-publicacao`)
